# Grafiora website

Source files (code only) for the Grafiora website — AI UGC video ads.

Live site: https://grafiora.vercel.app

This repository holds the HTML, CSS, JavaScript, SVG, sitemap and robots
files. Video files, posters and fonts are not stored here; they are deployed
to Netlify separately with the full site package, so deploying from this
repository alone will not include them.
